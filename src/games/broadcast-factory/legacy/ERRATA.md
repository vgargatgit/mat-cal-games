# Broadcast Factory Errata

Use this file to record confirmed or suspected content, validation, rendering, accessibility, or mathematical issues.

Logging an issue here does **not** authorize a behaviour change. A separate implementation request is required before modifying the game.

## Entry template

```markdown
## ERR-000 — Brief title

**Status:** Open  
**Date identified:** YYYY-MM-DD  
**Level:** Level title or number  
**Question:** `question-id`  
**Seed:** `seed`

### Expected behaviour

Describe the mathematically and pedagogically correct result.

### Actual behaviour

Describe what the game displayed, accepted, rejected, or omitted.

### Mathematical impact

Explain whether the issue affects values, shape, orientation, dependencies, terminology, or only presentation.

### Workaround

Describe a temporary learner or author workaround, if one exists.

### Status notes

- YYYY-MM-DD — Opened.
```

# Diagonal Detective Errata

Use this file as the local, append-only record of confirmed or suspected mathematical and behavioral issues.

When a request says to **log only**, add an entry here and do not change game behavior.

## Entry template

```markdown
## ERR-000 — Brief issue title

**Status:** Open  
**Date identified:** YYYY-MM-DD  
**Level:** Level name or number  
**Question:** `question-id`  
**Seed:** `seed-or-n/a`

### Expected behaviour

Describe the mathematically and pedagogically correct behaviour.

### Actual behaviour

Describe what the game currently does.

### Mathematical impact

Explain whether the issue changes a derivative, dependency path, zero reason,
classification, convention, or only presentation.

### Workaround

Give a learner or developer workaround, or write `None known`.
```
